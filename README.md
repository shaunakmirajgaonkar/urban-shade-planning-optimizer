# Urban Shade Planning Optimizer — ShadePlan Local

Local-first Streamlit planning workspace for pedestrian heat exposure and urban-shade intervention prioritization.

## Features
- Heat-exposure screening
- Shade-deficit analytics
- Pedestrian exposure analysis
- Tree, shade structure, cool-roof and shaded-walkway planning
- Scenario-weighted intervention planner
- CSV upload/export
- No external APIs

Outputs are planning heuristics and should be validated with field measurements and qualified professionals.
